# 全排列组合权利要求防线与竞品专利规避手册

本手册用于指导第 1 步（竞品规避拆解）与第 2 步（权利要求网架构设计），兼顾**最大保护覆盖面**、**高创造性答辩抓手**以及**实审分案灵活性**。

---

## 一、竞品专利定向规避与 FTO 初筛规程

1. **检索优先级与零中断降级**：
   - 若用户已提供对比文件号或 PDF，直接逐条拆解其**独立权利要求**的全部技术特征；
   - 如需补充检索，可调用 `patent-disclosure-skill` 的 `cnipa_search.py` / `gp_search.py`（注意 `gp_search.py` 单次请求，遇退出码 `4` / `429` 严禁死循环重试），若遇 WAF 或限流，立即无缝改用内置 `search_web` 查询 Google Patents / 公开专利文本，绝不卡死主流程。
2. **最高法「全部技术特征覆盖原则」比对逻辑**：
   - **产品避让他人授权专利（防侵权）**：只要我方实物缺少对方独立权利要求中的**至少一项必要技术特征**（且不构成等同替换），即不落入其字面范围。典型硬件结构避让抓手包括：
     - *电路/器件空间解耦*（如竞品权 1 限定「探头端壳体内部设有包含电池、处理器与无线通信芯片的集成基板」→ 我方将主控与模数转换电路外置于主机仓，探头壳体内仅保留无源感测单元，并在从权中正向写明该分离结构）；
     - *物理传路重构*（如竞品限定「对向双端跨腔透射光路/声路」→ 我方改为单侧同窗收发并增设延伸至端面的遮挡隔筋，有源收发器件远置并通过导波件耦合）；
     - *机械限位与缓冲机理重构*（如竞品限定「机械铰链转轴浮动机构」→ 我方改为无转轴的预压弹性体层配合沉台止挡台阶双态限位）。
   - **我方专利争取授权（具备新颖性与创造性）**：不要把单纯的「工位数量增减」或「常规材料简单替换」单独裸露在独权 1；应将**各变型共有的精巧机械配合闭环特征**（如「一体分格框架止挡台阶 + 背装凸缘肩 + 预压解耦弹性层双态限位」或算法类的「跨通道质量门控与残差自适应补偿步骤」）写入独权 1。
3. **强制区分「已授权公告文本 (`B`)」与「申请公布文本 (`A`)」**：
   - 在《复核记录与规避分析.md》中必须明确区分对比文献是授权公告（如 `CN...B`）还是公开申请（如 `CN...A`），并声明：*「基于现有公开文本完成定向结构比对；产品上市前应结合最终量产硬件、启用的软件功能及届时有效的官方登记簿授权权利要求做正式自由实施（FTO）核查。」*

## 二、多组独立权利要求与「全排列组合」布局架构

### A. 硬件/结构类发明推荐三独权架构（15–20 项）

| 组别 | 权项范围示例 | 战略作用与写法要点 |
| :--- | :--- | :--- |
| **第一组：核心组件独权 + 拓扑/混排从权网** | **独权 1** + 从权 2–13 | • **独权 1**：用「至少一条分隔肋围成至少两个装配口」（不锁死固定区数）+ 核心装配/浮动闭环机理卡住主干；未受载态同时覆盖「齐平延伸或微凸出」两种公差基准。<br>• **机理细化从权**：解耦槽、走线让位通道、差异化硬度/减薄腔、主流弹性体/发泡材料马库什并列、刚性壳体 vs. 柔性复合表层双路线、蛇形/FPC 抗疲劳引线。<br>• **排列组合穷举从权**：① 分区拓扑穷举（长轴等分/不等分、宽向/斜向、三区及以上、左右对称/异构）；② 工位选配穷举（纯电学阵列、光电混排、电学+温压湿辅助传感、同轴复合模组混排）。 |
| **第二组：高价值核心子模组独立权利要求** | **独权 14** + 从权 15–16 | • **防绕开设计**：若竞品不采用我方的多分格基座框架，而是换用单腔壳体但照抄我方的「外环功能件 + 翻边绝缘衬套 + 局部压环 + 同轴双层缓冲垫」复合子模组，独权 14 可直接单独卡住该子模组！<br>• **单一性分案预案**：与独权 1 共享核心配合与缓冲技术特征；在《问题清单.md》注明若实审提单一性意见可直接拆分为发明分案。 |
| **第三组：整机系统与动态通道选通独权** | **独权 17** + 从权 18–20 | • 保护搭载该组件或子模组的终端整机设备；<br>• 固化主控外置与远置光路等竞品避让特征；<br>• 用「多路通道选通矩阵」动态组合相邻差分、跨区交叉差分或参考端切换模式，使物理阵列布局不被单一采集模式绑死。 |

### B. 软件/算法流程类发明推荐四独权架构（10–14 项）

1. **独权 1（方法）**：`一种……处理方法，其特征在于，包括：` 按数据流闭环写清核心步骤（避免纯数学公式裸奔，每个公式参数必须绑定具体的物理/业务传感输入与工程控制输出）。
2. **从权 2–7（分支与鲁棒性穷举）**：特征提取/融合子步骤、异常退化/缺损通道自适应降级分支、在线校准/阈值动态更新、多场景参数配置表。
3. **独权 8（装置/系统模块）**：与独权 1 严格一一对应的功能模块架构（对应附图中的虚线框模块图）。
4. **独权 9–10（电子设备 & 计算机可读存储介质）**：标准处理器+存储器执行权 1–7 任一项方法的系统级闭环保护。

## 三、旁路交付文件模板要求（不入国知局正式递交件）

每次交付除五分件 Word 外，同步维护两份精炼旁路文档：
1. **`复核记录与规避分析.md`**：用一张 Markdown 表格列出核心竞品专利号、对方权要核心限定、本案具体规避结构/算法差异、以及上市前待跟踪事项；附多组权利要求防线摘要。
2. **`问题清单.md`**：汇总待发明人/代理师定稿确认的著录信息、工程示例数值范围校核建议、分案预案及电子申请 XML 转换提醒，并在聊天回复末尾以 `## 交付后请确认` 标题简要提示。
